# Computational Geomechanics Portfolio

## About

This repository presents my research portfolio in Computational Geomechanics, Rock Mechanics, Numerical Modelling, Geohazards, and Multiphysics Processes.

My work combines field investigations, laboratory testing, numerical simulation, probabilistic analysis, and scientific computing to study the behaviour of geomaterials and geotechnical systems across scales.
